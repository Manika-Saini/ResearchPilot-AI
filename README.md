# ResearchPilot AI

An AI-powered research assistant designed to help users understand,
analyze, and interact with research papers.

## Current Status

🚧 Under Development

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- HTML
- CSS
- Bootstrap
- Hugging Face
- FAISS
- Docker
- AWS

## Planned Features

- Research paper upload
- PDF text extraction
- AI-powered summarization
- Question answering using RAG
- Paper comparison
- Quiz generation
- Flashcard generation
- Research notes
- User authentication
